#     Hearts-of-Iron-IV-OST

A mod that adds the Hearts of Iron IV OST into Unciv

![alt text][HOI4]

[HOI4]: https://jetta.vgmtreasurechest.com/soundtracks/hearts-of-iron-iv-original-game-soundtrack-2019/00%20Front.jpg

#     Installation

1. Load Unciv
2. Visit mods
3. Find and download "Hearts Of Iron IV OST"
4. Enable "Permanent audiovisual mod"

##    Note.

The music for this mod is ripped from YouTube
